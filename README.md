Proje Yazarı: Berkay Yoğurtçu
# Projenin Adı: Kod-Asistan v0.1
## Projenin Amacı: Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak
## Projenin Hedefleri: v1.0 Akıllı Menü, v2.0 Veri Saklama
## Projenin Kapsamı: Kritik Eşik
1.Başla  
2.​Eğer Su_seviyesi > 50 ise 4. adıma git.  
3.​Değilse kapakları kapalı tut.
4.Saat = saat + 1, Adım 2'ye git.  
5.​Tahliye saatini ve kritik su seviyesini yazdır.  
6.​Bitir
